Django Project: NFTrees

Class: CSCI 258 – Web Application Development

📝 Assignment Description:

The project's main objective was to have students group together into teams of 3-8 people, and collaboratively develop a web application using Django for the Final Project.

🖼 Project Screenshot:

📂 My Work:

My work includied several things. Firstly, I was the weekly scrum master during the beginning of the project, giving my 4 team members each tasks to do - mainly basic stuff like creating the Django prpject

Secondly, I helped create downloading functionality for customers who purchased their images, along with test other team member's branches for errors, bugs, and so on

Third and finally, I helped present the final product during the class's final presentation week

💡 What I Learned:

This project has given me a greater insight into how to run and work within a group project. It's difficult to put into words my feelings, so I'll try to say it simply:

  • Communication is key and can be very difficult to do when working remotely or asynchronously. Without it, the project will likely fail.
  • Version control (Git/GitHub) is essential for collaborative coding projects.
  • Testing and code reviews help maintain code quality and catch bugs early.
  • Flexibility and adaptability are important when working with a team.

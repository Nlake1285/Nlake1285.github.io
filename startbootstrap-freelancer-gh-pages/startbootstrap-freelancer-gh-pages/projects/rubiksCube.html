Rubik's Cube

Class: CSCI 152 – Interdisciplinary Computer Science II

📝 Assignment Description:

This project tasked us with creating a Rubik's Cube in the Java programming language.

🖼 Project Screenshot:

📂 My Work:

The final submission ended up being a printed version of the game that could be played through the terminal window. The main moveset was programmed into a switch-case loop that took advantage of array position swaps to move the pieces

💡 What I Learned:

One of the biggest things that I learned from the project was how array index switching worked along with different loop functions in Java

Python Blackjack

Class: CSCI 151 – Interdisciplinary Computer Science I

📝 Assignment Description:

This assignemnt tasked students with creating the game of Blackjack in Python using recursion and beginner-level python priciples

🖼 Project Screenshot:

📂 My Work:

The final project included 4 python files, each for the cards, the deck, the player, and the game itself. The game would print in a loop on the terminal and behave like the game of Blackjack (pardoning not being able to double down)

💡 What I Learned:

This project helped me understand how to take on larger-scale projects in python, along with how to budget file space and method runtime. On top of that, the game was very addicting. Big money, no whamies!
